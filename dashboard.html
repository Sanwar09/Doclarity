Doclarity Architecture & Ops Dashboard
Air-Gapped & Standalone Ready
🎯 Mission & System Purpose

Doclarity is an enterprise-grade, offline-first Legal Document Intelligence & RAG platform. It ingests complex contract documents, performs automated entity/clause parsing via SpaCy NER and Regex, executes semantic vector indexing, and provides hybrid intelligent contract comparison and conversational Q&A.

Zero Build Required Hybrid AI (Gemini / Ollama) In-Memory RAG
⚡ Tech Stack Specification
  • Frontend UI: React 18, Vite, Tailwind CSS, Lucide Icons, PDFjs
  • Backend API: Node.js, Express.js, Multer file parser
  • NLP & Extraction: Python 3.11+, SpaCy NER, Tesseract OCR, Mammoth
  • AI & RAG Engine: Gemini 2.5 Flash, Ollama fallback, Vector Embeddings
  • Auth & Persistence: Supabase Auth & Storage / Mock local fallback

Interactive 5-layer visual pipeline representation. Click any layer step to expand architectural mechanics, source files, and payload specifications.
Layer 1 Document Ingestion & Multi-Modal Text Extraction
PDF, DOCX, Images

Incoming contract documents are validated and processed based on file extension. Raw text and visual layers are extracted securely.

Key Components: pdfjs-dist (PDF rendering), mammoth (Word DOCX), Tesseract.js / Python Tesseract (OCR fallback for scanned docs)
Layer 2 Entity Structure & Legal Clause Parsing
SpaCy + Regex Rules

Sub-process executes `spacy_ner.py` to extract high-value entities (Parties, Dates, Governing Law, Monetary Obligations, Termination Clauses) and applies regex boundaries for structural clause categorization.

Key Components: spacy_ner.py, en_core_web_sm, Custom Clause Regular Expressions
Layer 3 Hybrid Intelligence & Analysis Engine
Gemini 2.5 Flash / Ollama

Combines structured deterministic analysis with generative LLMs. If `GEMINI_API_KEY` is present, routes to Gemini 2.5 Flash; falls back gracefully to local Ollama or static rules if air-gapped/offline.

Key Components: @google/genai, Local Ollama HTTP Bridge, Dynamic Risk Assessment Model
Layer 4 RAG Chunking, Embeddings & Citation Vector Index
In-Memory Vector Store

Chunks extracted contract text into semantic paragraphs (500 tokens with 50-token overlap). Embeddings generated to allow top-k vector similarity search for contextual conversational chatbot answers with citations.

Key Components: Chunking Tokenizer, Cosine Similarity Indexer, Citation Generator
Layer 5 Interactive Frontend UI & API Endpoint Layer
React + Express

Exposes clean web UI views for end users and developers to upload contracts, inspect side-by-side comparisons, query conversational bots, and export PDF audit reports.

Key Files: App.jsx, Analysis.jsx, Compare.jsx, AIChatBot.jsx, ClauseExplorer.jsx
POST /api/upload
Uploads a document (PDF, DOCX, TXT, Image) for parsing and initial text extraction.
